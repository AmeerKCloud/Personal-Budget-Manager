## Personal Budget Manager

A simple, modular, object-oriented Python app that allows you to
track expenses, income, categories, and remaining budget. This project was built
using only foundational Python concepts while still maintaining clean, organized,
and industry-style project structure.

## Features
- Add income transactions
- Add expense transactions
- Automatically track total spending
- View remaining budget
- Categorize all transactions
- Error handling for invalid input
- Modular, OOP-based architecture

## Technologies / Concepts Used
- Classes, objects, attributes, methods
- Dictionaries, lists
- Loops & conditionals
- User input & output
- Custom modules and imports
- Error handling (try/except)
- Basic data file usage
- Simple separation of concerns
- Testing with `unittest`
